### q18 (hard): fail

Which department had the highest attrition rate in fiscal year 2026, and what was it?

- Why: no generated column holds the values of department (e.g. 'product')
- Expected 1 row(s) ['department', 'attrition_rate']: [["Product", 0.18584521384928718]]
- Got 1 row(s) ['department', 'exits', 'average_headcount', 'attrition_rate_pct']: [["Engineering - Security", 6, 31.934246575342467, 18.78860672614962]]

```sql
-- Interpretation: "department" = team/department row in dim_org (department_id), where people are assigned.
-- FY2026 = 2025-04-01 to 2026-03-31. Attrition rate = FTE exits in period / average FTE headcount
-- in period (FTE headcount rows / days in period), per department. Departments with no headcount are excluded.
-- Rate is expressed as a percentage of the period (not annualised).
with period as (
    select date '2025-04-01' as start_date, date '2026-03-31' as end_date
),
exits as (
    select t.department_id, count(*) as exits
    from analytics.fct_terminations as t, period as p
    where t.termination_date between p.start_date and p.end_date
    group by t.department_id
),
hc as (
    select h.department_id,
           countif(h.is_fte) / (date_diff(p.end_date, p.start_date, day) + 1) as average_headcount
    from analytics.fct_headcount_daily as h, period as p
    where h.snapshot_date between p.start_date and p.end_date
    group by h.department_id, p.start_date, p.end_date
)
select o.department_name as department,
       coalesce(e.exits, 0) as exits,
       hc.average_headcount,
       100 * coalesce(e.exits, 0) / hc.average_headcount as attrition_rate_pct
from hc
join analytics.dim_org as o on o.department_id = hc.department_id
left join exits as e on e.department_id = hc.department_id
where hc.average_headcount > 0
order by attrition_rate_pct desc
limit 1
```
